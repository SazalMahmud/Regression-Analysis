Regression Analysis Project
Overview
This project analyzes the impact of Advertising Spend, Salespersons, Customer Visits, and Discount Percentage on Sales Revenue using regression analysis techniques in Microsoft Excel.

Objectives
Identify factors affecting Sales Revenue
Apply Simple and Multiple Regression Analysis
Assess multicollinearity using Correlation Matrix and VIF
Evaluate model performance using R², F-statistic, and p-values
Select the most significant variables using Backward Elimination
Dataset Information
Observations: 105
Dependent Variable: Sales Revenue
Independent Variables
Advertising Spend
Salespersons
Customer Visits
Discount %
Methods Used
Exploratory Data Analysis (EDA)
Correlation Analysis
Simple Linear Regression
Multiple Linear Regression
Multicollinearity Analysis (VIF)
Residual Analysis
Model Selection
Key Findings
Advertising Spend showed the strongest relationship with Sales Revenue.
Simple Regression achieved R² = 0.516.
Multiple Regression achieved R² = 0.714.
Advertising Spend, Salespersons, and Customer Visits were significant predictors.
No multicollinearity issues were detected.
Final Regression Model
Sales Revenue = 13258.47 + 2.501(Advertising Spend) + 1953.01(Salespersons) + 5.501(Customer Visits)
